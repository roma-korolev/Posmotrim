Редактирование событий

Это временная служебная страница для управления фотографиями событий. Она не добавлена в навигацию сайта и не предназначена для конечных пользователей. Для каждого события можно указать главное фото (отображается в афише и подборках) и фото для листалки на странице самого события. Указывайте имя файла — файл должен лежать в папке images в корне проекта. Расширение указывать не обязательно (например, можно написать просто event1 вместо event1.jpg) — оно будет подобрано автоматически. Изменения хранятся только в этой вкладке браузера: чтобы сохранить их насовсем, скачайте обновлённый events.js и замените им файл в проекте.
